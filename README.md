### What I learned

In this challenge, I practiced structuring a component using HTML and styling it with modern CSS. I also learned how to use CSS Variables for a clean, maintainable color system:

```css
:root {
  --White: hsl(0, 0%, 100%);
  --light-gray: hsl(212, 45%, 89%);
  --gray-blue: hsl(216, 15%, 48%);
  --dark-blue: hsl(218, 44%, 22%);
}
